# 寶箱卡單張重抽 設計

日期：2026-11-25
狀態：設計已確認（使用者 2026-11-25）

## 背景

選卡畫面每張卡底下有三顆按鈕：🃏 重抽卡片（單張，每局 10 次）、🎯 專注（2 次）、🚫 放逐（4 次）；卡片下方另有 🔄 重抽全部（5 次）。
程式已經認得單張重抽按鈕（`CardLayout.FindButtons` 的 `ActKind.Reroll`，含剩餘次數），但選卡決策（`CardDecider.Decide`）從來不用它，每局 10 次都浪費。

## 規則（使用者確認）

只用在**寶箱卡**，技能卡不用單張重抽。

1. 寶箱卡畫面上，如果沒有任何一張是「要的」：
   1. 有可以按的單張重抽 → 挑一張卡按它的「重抽卡片」；畫面更新後重新判斷，一直重抽到出現要的卡。挑哪一張見下一節。
   2. 單張重抽都用完（或都按不了）→ 按「重抽全部」（可以按的話；寶箱卡可以把重抽全部用光，使用者確認）。
   3. 兩種都用完 → 照原本的規則選一張（稀有度優先等）。
2. 有要的卡 → 照原本的規則選（原本的規則已經會優先選這些卡）。
3. **組隊時**（`partyRole` 是 leader 或 member；選卡有秒數限制）每個寶箱畫面最多重抽 3 次（單張與重抽全部合計），之後照原本的規則選。單人不限。畫面消失（選完）後次數歸零。

### 單張重抽挑哪一張（使用者確認：挑抽得出要的）

單張重抽只會換成「同一寶箱欄位的不同裝備」（Wiki），也就是同一類：藥水換藥水、神器換神器。所以：

- 先認出每張卡的類別：卡名對到 schema 的道具分類（`EngineSchema.Items`：藥水、秘藥、祝福、料理），神器卡（`IsDeity`）是「神器」類；對不到的是「未知」。
- 一類「抽得出要的」：這一類裡有勾「優先」的道具、有這局拿過的道具、有尋寶道具（尋寶率還沒到上限、不是活動時）；神器類則是優先清單裡有神器（沒打 ✕；已鎖定時只有鎖定的那個）。
- 從「抽得出要的」而且單張重抽可以按的卡裡隨機挑一張；都沒有才從所有單張重抽可以按的卡裡隨機挑。

### 「要的」卡（任一符合就算）

- 面板「選卡 → 道具」勾了「優先」的道具（`itemPrio`）。
- 面板「神祇」頁優先清單裡的神器（`deity` 清單，同既有的神祇比對 `SameDeity`／`OcrFix`），而且沒有打 ✕；這局已經鎖定神器時（`deityLock` 開著、`RunPickState.DeityLock` 有值），只有同一個神器算。
- 尋寶率卡（`HasTreasure`），而且尋寶率還沒到上限、這局不是活動（同既有的 `noTreasure` 判斷）。
- 這局已經拿過的道具再次出現（升級它）：PickerFlow 選了寶箱卡時把卡名記進 `RunPickState`（新欄位，例如 `Owned`），比對時去掉空白與「+N」。

強制不選的卡（道具 ✕、神器 ✕、技能「不選」）永遠不算要的。

### 開關

新規則 `chestReroll`（升級分頁，接在 `autoChest` 後面）：「寶箱卡都不是要的時，隨機單張重抽直到出現要的（單張用完改按重抽全部）」，預設開。
加在 `RoHelper/Engine/engine.js` 的 `RULES`，用 `tools/gen-schema.js` 重新產生 `schema.json`（`BuiltInSchemaTests` 會檢查兩邊一致）。新版面板依 schema 自動長出這個開關。

### 跟其他規則的關係

- `autoChest`（六格都有了按遊戲的自動寶箱）照舊優先：交給遊戲之後不會再判斷。
- 「全部都是強制不選的卡 → 重抽全部」照舊。
- 重抽後的等待沿用 `PickerFlow` 的 `Settle`（同放逐、專注、重抽全部）。

## 實作重點

- `PickDo` 新增 `RerollCard`（單張重抽，Index＝哪一張）。
- `CardDecider.Decide` 新增參數：道具分類（schema 的 Items）、隨機函式（預設 `Random.Shared.Next`，測試傳固定值）、這個畫面還能重抽幾次（組隊 3 減已用，單人不限）。
- `PickerFlow.Act` 處理 `RerollCard`：點那張卡的單張重抽按鈕、等 `Settle`；記錄這個畫面重抽了幾次（`Gone()` 歸零）。
- `PickSettings` 新增 `ChestReroll`、`Party`。

## 測試

- 寶箱卡、三張都不是要的、單張重抽可按 → `RerollCard`。
- 挑卡：有一張的類別抽得出要的 → 挑那張；多張符合時用隨機函式從中挑；都不符合 → 從全部可按的挑。
- 單張重抽都不能按、重抽全部可按 → `Reroll`。
- 兩種都不能按 → 照原規則 `Pick`。
- 有勾選的道具／優先神器／尋寶率卡（未達上限）／這局拿過的道具 → 不重抽，照原規則選。
- 尋寶率已達上限（或活動）時尋寶率卡不算要的 → 會重抽。
- 升級卡不會單張重抽。
- `chestReroll` 關掉 → 不重抽。
- 組隊時同一畫面重抽滿 3 次 → 照原規則選；單人不受限。
- `PickerFlow`：`RerollCard` 點對位置、等待 `Settle`；選了寶箱卡會記進 `Owned`；畫面消失後重抽次數歸零。
