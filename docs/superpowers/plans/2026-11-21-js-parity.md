## 第 1 批

### Task 1: HP 條（HpReader）＋ HP 低停止走位（lowHpStop）

**Files:** Create `RoHelper/Vision/Field/HpReader.cs`；Modify `FieldSettings.cs`、`FieldPlanner.cs`、`VisionEngine.cs`、`DevApiHost.cs`（/field 加 `hp`）；Test `HpReaderTests.cs`、`FieldPlannerTests.cs`

- 畫面左上角角色框裡的 HP 條（實測 dpr 1：大約 x 94～310、y 43～57；填滿部分是藍色，空的部分是深色；上面印著「112 / 112」白字）。
- `HpReader.Read(Frame f, double dpr) → double?`（0～1）：在 HP 條那一列（取條的垂直中間附近幾列，避開白字）從左往右看「藍色填滿」像素的最右邊位置 ÷ 條寬。條的左右邊界要先用像素找出來（深色外框），不要寫死寬度。找不到條（不在野外）回 null。
- 用 fixture 實測藍色和深色的 RGB 後寫成常數（註解寫實測值）。測試：`野外1`、`野外4`、`野外2寶箱` 都是滿血 → ≥ 0.97；合成測試：把 fixture 的 HP 條右邊 60% 塗成空條的深色 → 0.35～0.45；純色畫面 → null。
- `FieldSettings` 加 `LowHpStop`、`LowHpStopN`（cfg `lowHpStop` 預設 false、`lowHpStopN` 預設 30）。
- `FieldPlanner.Step(..., double? hp = null)`：`LowHpStop && hp < N/100` → `("HP 過低，停止走位", null)`（同 JS 1086 行，在 SeekEvery 檢查之前）。
- `VisionEngine`：在野外每輪讀 HP（純像素，很便宜），傳給 Step。
- commit `feat: 讀 HP 條，HP 過低停止走位`

### Task 2: 太遠的東西先不撿（farLimit）

**Files:** Modify `FieldSettings.cs`、`FieldPlanner.cs`；Test `FieldPlannerTests.cs`

- JS（999～1001 行）：離「自己」超過地圖大小一半的目標先不追，王的掉落物例外。視覺模式用小地圖像素：`farMax = max(Map.Width, Map.Height) × 0.5`，磁鐵／寶箱離自己超過 farMax 就不考慮（掉落物不受限）。`FieldSettings.FarLimit`（cfg `farLimit`，預設 true）。
- 測試：寶箱在 farMax 外 → 不追（繞圈）；在 farMax 內 → 追；掉落物在 farMax 外仍追；FarLimit 關 → 追。
- commit `feat: 太遠的寶箱、磁鐵先不追（farLimit）`

### Task 3: 王死掉的地點（bossSpot）

**Files:** Modify `FieldPlanner.cs`（或新的 `BossTracker.cs`）、`FieldSettings.cs`；Test

- JS `trackBosses`（906～922 行）＋ `mapStep` 裡的 bossSpot 段（1108～1124 行）移植，但座標用**小地圖像素**（JS 用格子；視覺模式還不 OCR 座標）：
  - 每輪把 `mm.Bosses` 跟已知的王配對（距離 < 6 px 視為同一隻），更新位置、時間、`InView`（離小地圖區塊邊緣 > 4 px）。
  - 一隻王超過 1500 ms 沒看到、而且最後在小地圖裡面 → 判定死了，`bossSpot = (x, y, now)`。
  - bossSpot 開著（cfg `bossSpot`，預設 true）且 12 秒內：離 bossSpot < 2 px → 停留 1.5 秒後清掉，狀態「在王死掉的地方撿東西」，不點；否則狀態「跑到王死掉的地方」，往那邊點（`k = min(0.30, 0.06 + len·0.03)`，同撿掉落物）。超過 12 秒清掉。
  - 優先順序同 JS：在「卡住繞路」之後、「撿王的掉落物」之前；小地圖上有掉落物時，交給下面的撿掉落物（JS 1124 行 `if (!mm.loot.length) return;`）。
  - 卡住偵測照用 `CheckStuck`。
- 測試：王出現 → 消失 2 秒 → 往王的位置走；到了 → 停 1.5 秒 → 清掉；王跑到小地圖邊緣後消失 → 不算死；12 秒後清掉；有掉落物時改撿掉落物。
- `/field` 加 `bossSpot`。
- commit `feat: 王死掉後跑到死掉的地點（bossSpot）`

  - `Title`（第一行：「你存活下來了！」／「你死了」）→ `Outcome`：同 JS `outcomeOf`（活下／存活… → clear；死… → death；放棄 → abandoned；結束 → ended；其他 unknown）。
  - 本局五格（Job／時間／本局等級／怪物／頭目）：`Job`、`Time`（"14:20"）、`Secs`、`Level`、`Kills`、`Bosses`。OCR 讀到的是「標題 數值」上下兩行，用位置配對（同一欄的下面那行）。
  - `Exp`（「基本經驗: +339 · Base Lv 32」那行原文）、`Dps`（本局傷害每一列的原文，例如「1. 火箭術 163.2M · 191k DPS 34%」）、`DpsTotal`（「486M · 565k DPS」）。
