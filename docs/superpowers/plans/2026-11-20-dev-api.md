# 開發介面與自動存證據 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 讓 Claude 能自己「看、操作、驗證」：RoHelper 用 `--dev-api` 啟動時，在本機開一個 HTTP 介面（截圖、讀畫面、讀選卡、點擊、按鍵、暫停、存範本、看狀態紀錄）；同時在遇到異常（讀不到卡名、按鍵沒反應、例外）和每隔一段時間自動存下截圖＋紀錄，Claude 事後一次讀完再改程式。

**Architecture:**
1. `StatusHistory`：VisionEngine 每次狀態改變記一筆（時間＋文字），給開發介面和存證據用。
2. `EvidencePolicy`（純邏輯：這一輪要不要存、理由）＋ `EvidenceStore`（存 PNG＋JSON、超過上限刪最舊的）。VisionEngine 每輪結束時問一次。
3. `DevApiRouter`（純邏輯：路徑與參數 → 呼叫 `IDevApiHost`、回 JSON）＋ `DevApiServer`（HttpListener，只聽 127.0.0.1）＋ `DevApiHost`（真正的實作，所有動作切回 UI 執行緒做，因為 WebView2 只能在 UI 執行緒操作）。
4. `Program` 解析 `--dev-api[=port]`，有才開介面和自動存證據；沒有的話程式行為完全不變。

**Tech Stack:** .NET 8 WinForms、C# 12、System.Net.HttpListener（內建，不新增 NuGet）、xUnit 2.9.2

## Global Constraints

- **預設關閉**：只有命令列帶 `--dev-api` 才開 HTTP 介面和自動存證據。一般使用者雙擊 exe 時行為完全不變。
- **只聽本機**：prefix 固定 `http://127.0.0.1:{port}/`（預設 port 8765）。`127.0.0.1` 不需要系統管理員權限或 urlacl。不加驗證：只在使用者自己開發時用，而且只有本機程式連得到（寫進 README）。
- **不碰帳密**：不提供輸入文字的端點。登入由使用者自己做一次，WebView2 會記住。
- 全程不在遊戲網頁注入或執行 JS；CDP 只允許 `Input.*`（同前幾個計畫）。JS 引擎已停用，不要恢復。
- 座標一律是**截圖像素**（跟除錯視窗、範本一樣），送輸入前用 `ViewportMapper.ToCss` 換算。
- 所有碰到 WebView2／VisionKit／表單的動作都要在 UI 執行緒執行（HttpListener 的回呼在執行緒集區）。
- 不新增 NuGet 套件。
- 寫作風格依 `coding-style` skill：識別字英文；註解、XML doc、log、UI 文字、API 回傳的訊息繁體中文；每個 public class／record 要有 `<summary>`；單一語句的 if 不加大括號；刻意不做的事寫原因。
- 測試專案 `C:\Ro\RoHelper.Tests`。**RoHelper.exe 執行中時**，`dotnet test` 要加 `--artifacts-path <暫存資料夾>`（不然 exe 被鎖、建置失敗）；不要為了跑測試關掉使用者的程式。
- git repo 在 `C:\Ro`，分支 `vision-lobby-flow`（沿用），每個 Task 一個 commit，訊息結尾加 `Co-Authored-By:` 行。

## 不在這份計畫的範圍

- 野外走位（計畫 4）。
- 自動登入、輸入文字。
- 從遠端（非本機）連線、驗證機制。
- 讓 API 重新啟動程式：Claude 直接結束行程再 `dotnet run`。

```csharp
namespace RoHelper.Vision;

/// <summary>狀態紀錄的一筆：時間與面板上顯示的動作文字（不含「［視覺］」前綴）</summary>
public sealed record StatusEntry(DateTime Time, string Action);

/// <summary>
/// 視覺引擎的狀態紀錄（最近 N 筆，舊的丟掉）。給開發介面看「剛剛發生了什麼」、自動存證據時附上前後文。
/// 跟上一筆一樣就不記：主迴圈每 250 ms 回報一次，大部分時間都是同一句。
/// 執行緒：寫入在 UI 執行緒，讀取（開發介面）也切回 UI 執行緒，所以不加鎖。
/// </summary>
public sealed class StatusHistory(int capacity = 200)
{
    private readonly Queue<StatusEntry> _items = new();

    public string Last { get; private set; } = "";

    public void Add(DateTime time, string action)
    {
        if (action == Last && _items.Count > 0)
            return;
        Last = action;
        _items.Enqueue(new StatusEntry(time, action));
        while (_items.Count > capacity)
            _items.Dequeue();
    }

    /// <summary>最近 n 筆，舊的在前</summary>
    public IReadOnlyList<StatusEntry> Recent(int n) => [.. _items.Skip(Math.Max(0, _items.Count - n))];
}
```

規則（`EvidencePolicy.Check(string action, long now)` 回理由或 null）：

| 狀態文字開頭 | 理由 |
|---|---|
| `看起來像選卡但讀不到卡名` | `讀不到卡名` |
| `選卡按鍵沒反應` | `按鍵沒反應` |

| （以上都不是，且距離上次「定時」≥ periodicMs） | `定時` |

`IDevApiHost`（全部 async，實作負責切到 UI 執行緒）：

```csharp
namespace RoHelper.DevApi;

/// <summary>開發介面能做的事。座標都是截圖像素。實作（<c>DevApiHost</c>）負責切回 UI 執行緒</summary>
public interface IDevApiHost
{
    /// <summary>暫停狀態、局數、目前動作、最近 n 筆狀態紀錄、本局選卡狀態</summary>
    Task<JsonObject> StatusAsync(int n);

    /// <summary>截一張存到 shots/api（name 空的就用時間），回 { path, width, height, dpr }</summary>
    Task<JsonObject> ShotAsync(string? name);

    /// <summary>截一張，回每個大廳範本的最佳位置與分數、門檻，以及 ScreenReader 的判讀結果</summary>
    Task<JsonObject> ScreenAsync();

    /// <summary>截一張讀選卡；不是選卡畫面回 { picker: null }。有的話附上「現在設定下會怎麼選」</summary>
    Task<JsonObject> PickerAsync();

    Task ClickAsync(int x, int y);
    Task KeyAsync(char key);
    Task SetPausedAsync(bool paused);
    Task ReloadTemplatesAsync();

    /// <summary>從 shots 底下的一張 PNG（相對 shots 的路徑）裁一塊存成範本；已有同名範本時沿用它的搜尋範圍，沒有就整張畫面找</summary>
    Task<JsonObject> SaveTemplateAsync(string name, string shot, Rectangle crop, double threshold);

    /// <summary>最近 n 張自動存的證據（PNG 路徑，新的在前）</summary>
    Task<JsonObject> EvidenceAsync(int n);
}
```

路由表（`DevApiRouter.HandleAsync(string method, string path, NameValueCollection query)` → `DevApiResult(int Status, JsonNode Body)`）：

| 方法 路徑 | 參數 | 呼叫 |
|---|---|---|
| GET `/` | — | 回端點清單（方便 Claude 忘記時查） |
| GET `/status` | `n`（選，預設 30，1～200） | `StatusAsync` |
| GET `/shot` | `name`（選，不能含不合法檔名字元） | `ShotAsync` |
| GET `/screen` | — | `ScreenAsync` |
| GET `/picker` | — | `PickerAsync` |
| POST `/click` | `x`、`y`（必填，整數 ≥ 0） | `ClickAsync`，回 `{ ok: true }` |
| POST `/key` | `k`（必填，剛好 1 個英數字元） | `KeyAsync` |
| POST `/pause`、`/resume` | — | `SetPausedAsync(true/false)` |
| POST `/templates/reload` | — | `ReloadTemplatesAsync` |
| POST `/templates/save` | `name`、`shot`、`x`、`y`、`w`、`h`（必填）、`threshold`（選，預設 0.9，0.5～1） | `SaveTemplateAsync` |
| GET `/evidence` | `n`（選，預設 20，1～200） | `EvidenceAsync` |

- 錯誤：路徑不存在 → 404 `{ error: "沒有這個端點：GET /xxx" }`；方法不對 → 405；參數缺少或格式錯 → 400 `{ error: "<哪個參數、為什麼>" }`；host 丟例外 → 500 `{ error: ex.Message }`。
- `name`、`shot` 檢查：`name` 不能含 `Path.GetInvalidFileNameChars()`；`shot` 不能含 `..`、不能是絕對路徑（防止讀到 shots 以外的檔案）。

- [ ] **Step 1：寫測試**（假 host 記錄被呼叫的方法與參數）：
  - `/click?x=10&y=20` → 200，host 收到 (10, 20)
  - `/click?x=10` → 400；`/click?x=-1&y=0` → 400；GET `/click` → 405
  - `/key?k=1` → 200；`/key?k=12` → 400
  - `/nope` → 404
  - `/status` 沒給 n → host 收到 30；`n=999` → 400
  - `/templates/save?name=返回角色&shot=20261120-231129.png&x=912&y=627&w=80&h=28` → host 收到對的參數、threshold 0.9
  - `shot=../config.json` → 400；`name=a/b` → 400
  - host 丟例外 → 500，body 有 error
- [ ] **Step 2：實作**（路由用 `switch ((method, path))`；參數解析寫成小 helper：`TryInt(query, key, min, max, out int, out string error)` 等）
- [ ] **Step 3：測試全過 → commit `feat: 開發介面路由`**

  - Port 被占用時 `Start` 丟的例外由呼叫端接住、顯示在選單文字（不要讓程式開不起來）。
  - 測試：用假 host 起一個 server（隨機挑 20000～40000 的 port），`HttpClient` 打 `GET /` 得 200、`GET /nope` 得 404、`POST /key?k=1` 得 200。
- [ ] **Step 3：`DevApiHost : IDevApiHost`**（在 `Forms`，因為要用 `Control` 切執行緒）
  - 建構子拿：`Control ui`（GameForm）、`VisionKit kit`、`VisionEngine engine`、`PanelForm panel`、`ConfigStore config`、`EvidenceStore? evidence`。
  - `Task<T> OnUi<T>(Func<Task<T>> work)`：`ui.BeginInvoke` 執行 `work`，用 `TaskCompletionSource<T>` 把結果或例外傳回呼叫端。
  - `StatusAsync(n)`：`paused`、`runs`、`action`（engine.History.Last）、`history`（`[{t, a}]`）、`pick`（`picked`、`focused`、`banished`、`deityLock`、`gameAuto`）。
